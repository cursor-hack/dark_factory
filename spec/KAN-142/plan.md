# KAN-142 Implementation Plan

## Goal

Scaffold a self-contained Astro 4 + TypeScript static site at `clients/painters-demo/v1/web/` that satisfies the product-deploy contract (`npm run build` → `dist/`) and ships the agreed visual chrome (dark theme, gold accent, sticky header, attribution footer).

## Approach

Astro 4's official static output mode is a clean fit for the deploy pipeline (`docs/product-deploy.md`): it emits a fully static `dist/` and works on Node 18 (the runner version). All work is contained within `clients/painters-demo/v1/web/`; the repo root `package.json` is not touched.

## Files added

- `clients/painters-demo/v1/web/package.json` — `astro@^4.16.18`, `typescript@^5.6.3`, `npm run build` → `astro build`.
- `clients/painters-demo/v1/web/package-lock.json` — generated by `npm install` so `npm ci` works in CI.
- `clients/painters-demo/v1/web/astro.config.mjs` — `output: "static"`, directory build format.
- `clients/painters-demo/v1/web/tsconfig.json` — extends `astro/tsconfigs/strict`.
- `clients/painters-demo/v1/web/.gitignore` — ignores `node_modules/`, `dist/`, `.astro/`.
- `clients/painters-demo/v1/web/src/styles/global.css` — design tokens and base layout:
  - `--bg: #0c0c0e` (near-black background)
  - `--fg: #efe9dd` (off-white serif body)
  - `--accent: #c8a96a` (warm gold accent)
  - `--serif` Cormorant Garamond / Georgia stack for body/headings
  - `--sans` Inter / system-ui stack for header chrome
  - sticky `.site-header` with 5-dot nav styles, attribution `.site-footer`, and 5-section layout primitives
- `clients/painters-demo/v1/web/src/components/SiteHeader.astro` — sticky header: site title `Latvian Painters: Five Names That Matter` (with accent) and a 5-dot nav linking to `#section-1`…`#section-5` (placeholders).
- `clients/painters-demo/v1/web/src/components/SiteFooter.astro` — single-line attribution to `enciklopedija.lv`.
- `clients/painters-demo/v1/web/src/layouts/BaseLayout.astro` — imports global CSS, mounts `<SiteHeader/>` + `<main><slot/></main>` + `<SiteFooter/>`, sets `<title>` and meta.
- `clients/painters-demo/v1/web/src/pages/index.astro` — five empty `.painter-section` stubs (I–V) inside `BaseLayout`.

## Risks / unknowns

- **Visual rendering not browser-verified.** The build emits valid HTML/CSS and grep confirms the colour tokens and copy are present, but no headless browser pass was performed. Layout regressions (e.g. sticky-header offset on small viewports) would only surface in a real preview. Recommend running `npm run preview` or the Pages deploy before sign-off.
- **Custom display fonts not bundled.** The serif/sans stacks fall back to `Georgia` / system-ui. If a specific webfont (Cormorant Garamond, Inter) is required for brand fidelity, follow-up ticket should add `@fontsource/*` packages or `<link rel="preconnect">` to a font CDN.
- **Nav dots are static placeholders** as specified — they link to anchor stubs but have no painter content yet.
- **Lockfile size**: `package-lock.json` is ~5.5k lines (Astro pulls in Vite + Rollup + Sharp deps). This is normal for Astro 4 and required for reproducible CI installs.

## Out of scope (future tickets)

- Real navigation labels / smooth-scroll polish.
- Webfont loading.
- SEO/OG tags beyond the basic `<meta name="description">`.
